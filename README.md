📊 Proyek Data Warehouse & Analytics
Selamat datang di repositori Data Warehouse & Analytics Project.
Proyek ini mendemonstrasikan solusi lengkap data warehousing dan analytics mulai dari membangun data warehouse hingga menghasilkan insight yang dapat ditindaklanjuti untuk mendukung pengambilan keputusan bisnis.

🎯 Tujuan Proyek
1. Data Engineering – Membangun Data Warehouse
Objective
Membangun data warehouse modern menggunakan SQL Server untuk mengonsolidasi data penjualan, sehingga dapat digunakan dalam pelaporan analitik dan pengambilan keputusan strategis.
Spesifikasi
- Sumber Data: Impor data dari dua sistem (ERP & CRM) dalam format CSV
- Kualitas Data: Membersihkan dan menyelesaikan isu kualitas data sebelum analisis
- Integrasi: Menggabungkan kedua sumber ke dalam satu model data yang ramah untuk query analitik
- Lingkup: Fokus pada dataset terbaru (tidak perlu historisasi data)
- Dokumentasi: Menyediakan dokumentasi jelas mengenai model data untuk mendukung stakeholder bisnis dan tim analytics

2. Business Intelligence – Analytics & Reporting
Objective
Mengembangkan analitik berbasis SQL untuk memberikan insight mendalam terkait:
- Perilaku Pelanggan
- Performa Produk
- Tren Penjualan
Insight ini akan memberdayakan stakeholder dengan metrik bisnis utama, sehingga mendukung pengambilan keputusan strategis.
